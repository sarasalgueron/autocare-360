1. Propósito
Construir la primera capa navegable del frontend de ParkFlow360. Al finalizar, el proyecto tendrá un layout administrativo consistente, un menú lateral con estado activo y páginas independientes para Inicio, Clientes y Vehículos. Aún no se consumirá el backend: primero se dominará el flujo de navegación y la arquitectura visual.
Resultado esperado:  al ejecutar el proyecto, el usuario podrá navegar entre /, /clientes y /vehiculos sin recargar toda la aplicación. Una ruta inexistente mostrará una página 404 dentro del mismo layout.

4. Concepto previo: SPA y routing del lado del cliente
ParkFlow360 será una Single Page Application (SPA). El navegador carga la aplicación React y, a partir de allí, el router decide qué componente debe mostrarse según la URL. Navegar de /clientes a /vehiculos cambia la vista sin solicitar al servidor un documento HTML completamente nuevo para cada pantalla.
Flujo conceptual
Usuario hace clic en “Clientes”
        ↓
NavLink cambia la URL a /clientes
        ↓
BrowserRouter observa la nueva ubicación
        ↓
Routes busca la Route que coincide
        ↓
MainLayout permanece visible
        ↓
Outlet renderiza ClientesPage
5. Instalar React Router desde WebStorm
Abre la terminal integrada de WebStorm (Alt+F12) en la raíz del proyecto y ejecuta:
npm install react-router
1.  Espera a que npm termine sin errores.
2.  Abre package.json.
3.  Comprueba que react-router aparece entre las dependencias.
4.  Ejecuta nuevamente npm run dev y verifica que el proyecto sigue arrancando.
Importante:  en documentación y tutoriales antiguos puede aparecer react-router-dom. En esta guía se seguirá la API declarativa actual documentada oficialmente con el paquete react-router.

7. Configurar BrowserRouter en main.tsx
Reemplaza el contenido de src/main.tsx por el siguiente código:
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { BrowserRouter } from 'react-router';
import App from './app/App';
import './styles/global.css';
 
createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>,
);
Observa:  BrowserRouter envuelve a App. Por eso cualquier componente descendiente podrá usar las herramientas de React Router.

8. Convertir App.tsx en punto de entrada de la navegación
Abre src/app/App.tsx y deja que su única responsabilidad sea delegar el árbol de pantallas al router:
import AppRouter from '../routes/AppRouter';
 
export default function App() {
  return <AppRouter />;
}
9. Crear AppRouter.tsx
Crea src/routes/AppRouter.tsx. Aquí se declara qué componente corresponde a cada dirección.
import { Route, Routes } from 'react-router';
import MainLayout from '../layouts/MainLayout';
import DashboardPage from '../pages/DashboardPage';
import NotFoundPage from '../pages/NotFoundPage';
import ClientesPage from '../features/clientes/pages/ClientesPage';
import VehiculosPage from '../features/vehiculos/pages/VehiculosPage';
 
export default function AppRouter() {
  return (
    <Routes>
      <Route element={<MainLayout />}>
        <Route index element={<DashboardPage />} />
        <Route path="clientes" element={<ClientesPage />} />
        <Route path="vehiculos" element={<VehiculosPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Route>
    </Routes>
  );
}
La ruta index representa /.
clientes representa /clientes porque está anidada bajo la ruta de layout.
vehiculos representa /vehiculos.
* captura cualquier dirección que no coincida con las anteriores.
10. Crear el layout principal con Outlet
Crea src/layouts/MainLayout.tsx:
import { Outlet } from 'react-router';
import Header from '../components/common/Header';
import Sidebar from '../components/common/Sidebar';
 
export default function MainLayout() {
  return (
    <div className="app-shell">
      <Sidebar />
 
      <div className="app-shell__main">
        <Header />
        <main className="app-content">
          <Outlet />
        </main>
      </div>
    </div>
  );
}
Sidebar y Header son permanentes. Outlet es el punto variable: allí aparecerá DashboardPage, ClientesPage, VehiculosPage o NotFoundPage según la URL.
11. Crear el menú lateral con NavLink
Crea src/components/common/Sidebar.tsx:
import { NavLink } from 'react-router';
 
const menuItems = [
  { to: '/', label: 'Inicio', end: true },
  { to: '/clientes', label: 'Clientes' },
  { to: '/vehiculos', label: 'Vehículos' },
];
 
export default function Sidebar() {
  return (
    <aside className="sidebar">
      <div className="sidebar__brand">
        <span className="sidebar__brand-mark">P</span>
        <div>
          <strong>ParkFlow360</strong>
          <small>Administración</small>
        </div>
      </div>
 
      <nav className="sidebar__nav" aria-label="Navegación principal">
        {menuItems.map((item) => (
          <NavLink
            key={item.to}
            to={item.to}
            end={item.end}
            className={({ isActive }) =>
              `sidebar__link${isActive ? ' sidebar__link--active' : ''}`
            }
          >
            {item.label}
          </NavLink>
        ))}
      </nav>
    </aside>
  );
}
Punto de defensa:  debes poder explicar la diferencia entre un enlace HTML normal y NavLink, y qué representa isActive.
