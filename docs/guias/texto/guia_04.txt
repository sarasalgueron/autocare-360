1. Objetivos de aprendizaje
Comprender por que un formulario React se modela como estado y no como lectura directa del DOM.
Diferenciar inputs controlados y no controlados, identificando cuando conviene usar cada enfoque.
Usar useState con objetos para manejar formularios de varias entradas sin mutar el estado.
Tipar eventos de cambio y envio con TypeScript.
Validar datos antes de preparar el objeto que en una guia posterior sera enviado al backend.
Construir ClienteForm y VehiculoForm respetando los modelos definidos en la Guia 03.
Representar la relacion Cliente 1:N Vehiculo mediante un select controlado de clienteId.
Explicar oralmente el flujo: usuario -> input -> evento -> estado -> validacion -> submit -> payload preparado.

6. Implementar validaciones sin librerias externas
Primero aprenderemos la logica manual. Mas adelante podremos comparar con librerias como React Hook Form o Zod, pero un estudiante debe entender que problema resuelven antes de usarlas.
src/features/clientes/utils/clienteValidation.ts
import type { ClienteFormData } from '../types/ClienteFormData';

export type ClienteFormErrors = Partial<Record<keyof ClienteFormData, string>>;

export function validarCliente(data: ClienteFormData): ClienteFormErrors {
  const errors: ClienteFormErrors = {};

  if (!data.nombre.trim()) errors.nombre = 'El nombre es obligatorio.';
  if (!data.apellido.trim()) errors.apellido = 'El apellido es obligatorio.';
  if (!data.documento.trim()) errors.documento = 'El documento es obligatorio.';

  if (!data.email.trim()) {
    errors.email = 'El email es obligatorio.';
  } else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(data.email)) {
    errors.email = 'El email no tiene un formato valido.';
  }

  if (data.telefono && data.telefono.replace(/\D/g, '').length < 7) {
    errors.telefono = 'El telefono debe tener al menos 7 digitos.';
  }

  return errors;
}

src/features/vehiculos/utils/vehiculoValidation.ts
import type { VehiculoFormData } from '../types/VehiculoFormData';

export type VehiculoFormErrors = Partial<Record<keyof VehiculoFormData, string>>;

export function validarVehiculo(data: VehiculoFormData): VehiculoFormErrors {
  const errors: VehiculoFormErrors = {};
  const anioActual = new Date().getFullYear();
  const anio = Number(data.anio);

  if (!data.placa.trim()) errors.placa = 'La placa es obligatoria.';
  if (!data.marca.trim()) errors.marca = 'La marca es obligatoria.';
  if (!data.modelo.trim()) errors.modelo = 'El modelo es obligatorio.';
  if (!data.color.trim()) errors.color = 'El color es obligatorio.';
  if (!data.clienteId) errors.clienteId = 'Debe seleccionar un cliente.';

  if (!data.anio) {
    errors.anio = 'El anio es obligatorio.';
  } else if (!Number.isInteger(anio) || anio < 1950 || anio > anioActual + 1) {
    errors.anio = 'Ingrese un anio valido.';
  }

  return errors;
}

7. Construir ClienteForm con inputs controlados
El formulario mantendra un unico objeto formData. Cada input leera desde ese objeto y lo actualizara sin mutarlo.
src/features/clientes/components/ClienteForm.tsx
import { useState, type ChangeEvent, type FormEvent } from 'react';
import type { ClienteFormData } from '../types/ClienteFormData';
import { validarCliente, type ClienteFormErrors } from '../utils/clienteValidation';

const initialClienteForm: ClienteFormData = {
  nombre: '',
  apellido: '',
  documento: '',
  telefono: '',
  email: '',
  activo: true,
};

export default function ClienteForm() {
  const [formData, setFormData] = useState<ClienteFormData>(initialClienteForm);
  const [errors, setErrors] = useState<ClienteFormErrors>({});
  const [mensaje, setMensaje] = useState('');

  const handleChange = (e: ChangeEvent<HTMLInputElement>) => {
    const { name, value, type, checked } = e.target;

    setFormData((prev) => ({
      ...prev,
      [name]: type === 'checkbox' ? checked : value,
    }));
  };

  const handleSubmit = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    setMensaje('');

    const validationErrors = validarCliente(formData);
    setErrors(validationErrors);

    if (Object.keys(validationErrors).length > 0) return;

    const clientePayload = {
      ...formData,
      nombre: formData.nombre.trim(),
      apellido: formData.apellido.trim(),
      documento: formData.documento.trim(),
      email: formData.email.trim().toLowerCase(),
    };

    console.log('Cliente listo para API:', clientePayload);
    setMensaje('Datos validos. Cliente listo para enviarse al backend.');
  };

  return (
    <form className="entity-form" onSubmit={handleSubmit} noValidate>
      <div className="form-grid">
        <label>
          Nombre
          <input name="nombre" value={formData.nombre} onChange={handleChange} />
          {errors.nombre && <small className="field-error">{errors.nombre}</small>}
        </label>

        <label>
          Apellido
          <input name="apellido" value={formData.apellido} onChange={handleChange} />
          {errors.apellido && <small className="field-error">{errors.apellido}</small>}
        </label>

        <label>
          Documento
          <input name="documento" value={formData.documento} onChange={handleChange} />
          {errors.documento && <small className="field-error">{errors.documento}</small>}
        </label>

        <label>
          Telefono
          <input name="telefono" value={formData.telefono} onChange={handleChange} />
          {errors.telefono && <small className="field-error">{errors.telefono}</small>}
        </label>

        <label className="form-span-2">
          Email
          <input type="email" name="email" value={formData.email} onChange={handleChange} />
          {errors.email && <small className="field-error">{errors.email}</small>}
        </label>

        <label className="checkbox-field form-span-2">
          <input type="checkbox" name="activo" checked={formData.activo} onChange={handleChange} />
          Cliente activo
        </label>
      </div>

      {mensaje && <div className="form-success">{mensaje}</div>}

      <div className="form-actions">
        <button type="button" className="btn-secondary" onClick={() => {
          setFormData(initialClienteForm);
          setErrors({});
          setMensaje('');
        }}>
          Limpiar
        </button>
        <button type="submit" className="btn-primary">Guardar cliente</button>
      </div>
    </form>
  );
}

8. Construir VehiculoForm y representar Cliente 1:N
El formulario de Vehiculo introduce un select controlado. El usuario ve el nombre del cliente, pero el estado guarda clienteId. Esto representa la relacion desde el frontend.
src/features/vehiculos/components/VehiculoForm.tsx
import { useState, type ChangeEvent, type FormEvent } from 'react';
import { clientesMock } from '../../clientes/data/clientes.mock';
import type { VehiculoFormData } from '../types/VehiculoFormData';
import { validarVehiculo, type VehiculoFormErrors } from '../utils/vehiculoValidation';

const initialVehiculoForm: VehiculoFormData = {
  placa: '',
  marca: '',
  modelo: '',
  anio: '',
  color: '',
  clienteId: '',
  activo: true,
};

export default function VehiculoForm() {
  const [formData, setFormData] = useState<VehiculoFormData>(initialVehiculoForm);
  const [errors, setErrors] = useState<VehiculoFormErrors>({});
  const [mensaje, setMensaje] = useState('');

  const handleChange = (
    e: ChangeEvent<HTMLInputElement | HTMLSelectElement>
  ) => {
    const { name, value } = e.target;

    if (e.target instanceof HTMLInputElement && e.target.type === 'checkbox') {
      setFormData((prev) => ({ ...prev, [name]: e.target.checked }));
      return;
    }

    setFormData((prev) => ({ ...prev, [name]: value }));
  };

  const handleSubmit = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    setMensaje('');

    const validationErrors = validarVehiculo(formData);
    setErrors(validationErrors);
    if (Object.keys(validationErrors).length > 0) return;

    const vehiculoPayload = {
      placa: formData.placa.trim().toUpperCase(),
      marca: formData.marca.trim(),
      modelo: formData.modelo.trim(),
      anio: Number(formData.anio),
      color: formData.color.trim(),
      clienteId: Number(formData.clienteId),
      activo: formData.activo,
    };

    console.log('Vehiculo listo para API:', vehiculoPayload);
    setMensaje('Datos validos. Vehiculo listo para enviarse al backend.');
  };

  return (
    <form className="entity-form" onSubmit={handleSubmit} noValidate>
      <div className="form-grid">
        <label>
          Placa
          <input name="placa" value={formData.placa} onChange={handleChange} />
          {errors.placa && <small className="field-error">{errors.placa}</small>}
        </label>

        <label>
          Marca
          <input name="marca" value={formData.marca} onChange={handleChange} />
          {errors.marca && <small className="field-error">{errors.marca}</small>}
        </label>

        <label>
          Modelo
          <input name="modelo" value={formData.modelo} onChange={handleChange} />
          {errors.modelo && <small className="field-error">{errors.modelo}</small>}
        </label>

        <label>
          Anio
          <input type="number" name="anio" value={formData.anio} onChange={handleChange} />
          {errors.anio && <small className="field-error">{errors.anio}</small>}
        </label>

        <label>
          Color
          <input name="color" value={formData.color} onChange={handleChange} />
          {errors.color && <small className="field-error">{errors.color}</small>}
        </label>

        <label>
          Cliente propietario
          <select name="clienteId" value={formData.clienteId} onChange={handleChange}>
            <option value="">Seleccione un cliente</option>
            {clientesMock
              .filter((cliente) => cliente.activo)
              .map((cliente) => (
                <option key={cliente.id} value={cliente.id}>
                  {cliente.nombre} {cliente.apellido}
                </option>
              ))}
          </select>
          {errors.clienteId && <small className="field-error">{errors.clienteId}</small>}
        </label>

        <label className="checkbox-field form-span-2">
          <input type="checkbox" name="activo" checked={formData.activo} onChange={handleChange} />
          Vehiculo activo
        </label>
      </div>

      {mensaje && <div className="form-success">{mensaje}</div>}

      <div className="form-actions">
        <button type="submit" className="btn-primary">Guardar vehiculo</button>
      </div>
    </form>
  );
}

10. Integrar los formularios en las paginas
Para practicar estado adicional, mostraremos y ocultaremos el formulario con un boton. El objetivo no es aun insertar datos en la tabla; solamente controlar la interfaz.
Ejemplo de ClientesPage.tsx
import { useState } from 'react';
import ClienteForm from '../components/ClienteForm';
import ClienteTable from '../components/ClienteTable';
import { clientesMock } from '../data/clientes.mock';

export default function ClientesPage() {
  const [mostrarFormulario, setMostrarFormulario] = useState(false);

  return (
    <section className="feature-page">
      <div className="page-heading">
        <div>
          <p className="eyebrow">GESTION DE CLIENTES</p>
          <h1>Clientes</h1>
        </div>
        <button
          type="button"
          className="btn-primary"
          onClick={() => setMostrarFormulario((prev) => !prev)}
        >
          {mostrarFormulario ? 'Cerrar formulario' : '+ Nuevo cliente'}
        </button>
      </div>

      {mostrarFormulario && <ClienteForm />}
      <ClienteTable clientes={clientesMock} />
    </section>
  );
}

No confundir: Guardar en esta guia NO inserta todavia una fila ni llama a Spring Boot. Solo demuestra que el formulario produce un payload correcto. Persistencia y CRUD llegan despues.
