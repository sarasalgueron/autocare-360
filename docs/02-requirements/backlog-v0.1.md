# Backlog v0.1 — AutoCare 360

## Convención de prioridad

- P0: imprescindible para el flujo crítico del MVP.
- P1: importante para completar la operación.
- P2: complemento posterior.

### AC-001 — Registrar cliente y vehículo
**Prioridad:** P0
Como asesor de servicio, quiero registrar un cliente y su vehículo sin duplicar placa/VIN para poder asociarlos a futuras órdenes.

### AC-002 — Consultar catálogo de servicios
**Prioridad:** P0
Como asesor de servicio, quiero consultar el catálogo de servicios disponibles para poder incluirlos en una estimación.

### AC-003 — Abrir orden de servicio
**Prioridad:** P0
Como asesor de servicio, quiero abrir una orden de servicio para un vehículo para iniciar el ciclo de atención en el taller.

### AC-004 — Asignar tareas al técnico
**Prioridad:** P0
Como asesor de servicio, quiero asignar tareas técnicas con responsable dentro de una orden para que el técnico sepa qué debe ejecutar.

### AC-005 — Generar estimación
**Prioridad:** P0
Como asesor de servicio, quiero generar una estimación de servicios y repuestos, versionándola si cambian costos o alcance, para informar al cliente antes de avanzar.

### AC-006 — Aprobar o rechazar estimación desde móvil
**Prioridad:** P0
Como cliente, quiero aprobar o rechazar una estimación desde la app móvil para autorizar el trabajo sobre mi vehículo.

### AC-007 — Actualizar avance de tareas
**Prioridad:** P0
Como técnico, quiero actualizar el estado de mis tareas asignadas para reflejar el avance real del trabajo.

### AC-008 — Adjuntar evidencias
**Prioridad:** P1
Como técnico, quiero adjuntar evidencias con descripción a la orden para dejar constancia del trabajo realizado.

### AC-009 — Cerrar y entregar orden
**Prioridad:** P0
Como asesor de servicio, quiero cerrar las tareas obligatorias y registrar la entrega (fecha, kilometraje, observaciones) para finalizar la orden.

### AC-010 — Consultar historial de la orden
**Prioridad:** P1
Como cliente o supervisor, quiero consultar el historial completo de una orden para entender su trazabilidad.

### AC-011 — Recibir notificaciones
**Prioridad:** P1
Como cliente, quiero recibir notificaciones sobre eventos relevantes de mi orden para estar informado sin tener que consultar manualmente.

### AC-012 — Consultar reportes e indicadores
**Prioridad:** P1
Como administrador, quiero consultar reportes de tiempos y carga de trabajo para tomar decisiones operativas.

### AC-013 — Sugerir tareas con IA a partir de observaciones
**Prioridad:** P2
Como asesor de servicio, quiero que el sistema sugiera tareas estructuradas a partir de mis observaciones textuales, requiriendo mi confirmación, para agilizar el registro sin perder control humano.

> ATENCIÓN: Una historia no es "crear tabla", "hacer endpoint" ni "hacer formulario". Es una necesidad que genera valor para un actor. Las tareas técnicas aparecerán después para implementar la historia.
